Instructions for using these files: 

`tfupdate.sh` and `zhijack.sh` belong inside the `cubegm` folder. They should not cause issues with various clone consoles running TreeFrogUI or with my "fix adapter 0.05," which already includes these improvements. They are fully compatible with the R36HD, and the behavior should be similar for the R36SX.

`mount-helper.sh` This file contains the "magic" needed to get USB OTG working on the clone console you are using with TreeFrogUI; if you have the R36HD or R36SX running custom firmware, you shouldn't have any trouble running it. Installation is applied at `rootfs\etc\mdev`.
